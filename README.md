# repo-template

A starter template for new repositories.
Click **Use this template** on GitHub to create a new repo pre-populated with a sensible `.github/` setup, CI, Dependabot, and community health files.

## What's included

- **Issue templates** - structured bug report and feature request forms (`.github/ISSUE_TEMPLATE/`).
- **Pull request template** - `.github/PULL_REQUEST_TEMPLATE.md`.
- **CI workflow** - `.github/workflows/ci.yml`, a language-agnostic skeleton with placeholder lint/test steps to fill in.
- **Dependabot** - `.github/dependabot.yml`, keeps GitHub Actions up to date out of the box, with commented examples for common ecosystems.
- **Community health files** - `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `CODEOWNERS`, and a `LICENSE`.
- **AGENTS.md** - shared instructions for AI coding agents working in the repo.

## After creating a repo from this template

1. Replace this README with a description of your actual project.
2. Edit `.github/workflows/ci.yml` to run your project's real lint/test/build steps.
3. Uncomment the relevant ecosystem(s) in `.github/dependabot.yml`.
4. Review `CODEOWNERS` and `LICENSE`.
5. Adjust `AGENTS.md` for the project's stack and conventions.
